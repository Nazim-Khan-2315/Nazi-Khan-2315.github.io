# Nazim Khan — Interactive Data Analytics Portfolio

An interactive 3D Data Analytics portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**, showcasing skills across **MySQL**, **Python & Pandas**, **Excel**, **Power BI**, **Tableau**, and **R**.

![Project Banner](src/assets/images/python_pandas_3d_logo_1784975810183.jpg)

---

## 🌟 Key Features

- **Interactive 3D Technology Showcase**: Dynamic tilt cards showcasing proficiency in **MySQL**, **Python & Pandas**, **Excel**, **Power BI**, **Tableau**, and **R**.
- **Real Project Code & SQL Queries**: Interactive tabbed code viewers, sample datasets, and visual insights for each technology.
- **Instant Search & Category Filtering**: Quick filtering across technology categories (Database, Data Science, Spreadsheets, BI, Visualization, Statistics).
- **Direct Recruiter Connect**: Integrated 1-click contact links for Phone, WhatsApp, Email, and Resume download.
- **Responsive & Theme Adaptable**: Smooth light and dark mode toggling with landscape mobile optimization.

---

## 🚀 Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Motion (`motion/react`)
- **Data Visualization**: Recharts & D3
- **Data Parsers**: PapaParse (CSV) & SheetJS XLSX (Excel)
- **Icons**: Lucide React

## 💻 Getting Started Locally

### Prerequisites

Ensure you have **Node.js** (v18 or higher) and **npm** installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.

### Production Build

To build the application for production:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```

## 📦 How to Upload / Push to GitHub

### Method 1: Export Directly via AI Studio
1. Look at the top menu bar in AI Studio.
2. Click the **Export** / **Settings** menu.
3. Select **Export to GitHub** or **Download ZIP**.
4. If downloading ZIP, extract the files locally and follow Method 2.

### Method 2: Git Command Line (CLI)
1. Open your terminal in the project root directory.
2. Initialize a local Git repository (if not already initialized):
   ```bash
   git init
   ```
3. Add all project files:
   ```bash
   git add .
   ```
4. Create your first commit:
   ```bash
   git commit -m "Initial commit: Data Analyst Portfolio & Universal Data Studio"
   ```
5. Create a new empty repository on [GitHub](https://github.com/new).
6. Link your local repository to GitHub and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

## 🌐 Deploying to GitHub Pages

This project is pre-configured for automated hosting on **GitHub Pages**:

1. Push your repository to GitHub (following the steps above).
2. Go to your GitHub repository in your browser.
3. Click on **Settings** -> **Pages** (in the left sidebar).
4. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
5. Push any new commit to your `main` branch — the `.github/workflows/deploy.yml` workflow will automatically build and publish your app live at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`!
